# Fretlines в Codespaces

Приложение запускается само при каждом старте Codespace и слушает порт **8080**.

- Открыть: вкладка **Ports** внизу → строка «Fretlines» → значок глобуса. Ссылка вида
  `https://<имя>-8080.app.github.dev` открывается только под твоим аккаунтом GitHub, в том числе
  с телефона.
- Демо-песня «Am – F – C – G» появляется в библиотеке сама, через пару минут после первого старта.
- Если Codespace уснул (по умолчанию через 30 минут без дела), запусти его снова на
  https://github.com/codespaces — приложение поднимется само.
- Журнал сервера: `/tmp/fretlines.log`. Перезапуск: `bash .devcontainer/start.sh`.
- Обновить до свежей версии из GitHub (код, библиотеки, интерфейс, модели) и перезапустить:
  `git pull && bash .devcontainer/update.sh`. Старые разборы после этого предложат
  «Обновить разбор».

YouTube из облака иногда не отдаёт видео: серверы GitHub похожи для него на ботов. Файлы
работают всегда.
