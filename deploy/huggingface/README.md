# Fretlines

Гитарный аранжировщик для ансамбля: загружаешь песню и получаешь партии для 1–4 гитар — мелодию,
ритм, бас, перебор. Каждому по уровню, с табами, аккордами и плеером с гитарным звуком.

Это облачная копия для проверки. Space работает на бесплатном процессоре (2 ядра), поэтому
4-минутная песня разбирается минут 10–15. Загруженные песни стираются при перезапуске Space.
Ссылки с YouTube из облака часто не скачиваются: YouTube блокирует серверы. Файлы работают
всегда.

Исходники, запуск у себя на компьютере (`start.bat`) и документация — в репозитории на GitHub.
